# 003 - Active Workout V1 (Session UX + Logging)

## Goal
Improve in-session clarity and capture high-value training data.

## Includes
- Weight logging per set.
- Set progress dots/checkboxes.
- Circular rest countdown ring.
- Prominent TTS mute toggle pill.
- Explicit actions: Skip Rest vs Skip Exercise.
- Pause and resume workout session.
- Warmup + cooldown phases (AI-generated by muscle group, 10-20 min cooldown range).
- Mid-workout notes capture (stored now, AI usage later).
- Heart-rate zone indicator updates every 30-45s when available.

## Frontend Plan
- Extend exercise phase UI with per-set inputs and completion controls.
- Add rest-phase circular timer visual.
- Update top action area for clear audio controls.
- Add separate skip buttons with confirmation behavior.
- Add session state machine support for paused state.
- Add warmup and cooldown cards before/after main set flow.
- Add floating notes action during session.
- Add HR tile overlay with zone text and trend cue.

## Backend/Data Plan
- Expand workout session logging to store per-set loads, set completion, notes, and timing.
- Persist warmup/cooldown completion blocks.
- Store HR snapshots at interval during active sessions.
- Keep schema ready for future PR calculations and load charts.

## Dependencies
- Workout session schema migration.
- Device health permission and HR data availability checks.

## Acceptance Criteria
- Session can be paused/resumed safely.
- Per-set loads are saved and queryable per session.
- Rest readability and session action clarity improve.
